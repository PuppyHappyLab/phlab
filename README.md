# Puppy Happy Lab

寵學實驗室网站。基于 [Lab Website Template](https://github.com/greenelab/lab-website-template)，用 Jekyll 构建。

## 本地预览

```powershell
bundle install
bundle exec jekyll serve
```

浏览器打开 http://127.0.0.1:4000 。

## 内容

- `_config.yaml`：站点标题与链接
- `_members/`：成员
- `_projects/`：项目
- `_posts/`：博客
